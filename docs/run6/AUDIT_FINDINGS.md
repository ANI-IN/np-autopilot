# Run 6 — independent audit (B5)

Scope: security, permissions, edge cases, error handling, data integrity and resource limits, outside every stream's own list.
Method: the code paths were read end to end (`api/index.py` → `kb_routes` → `service` / `workspace` / `activity` → SQL and migrations),
and every "returns 500" claim was **reproduced** through the real WSGI app in-process against `kbtest_b5`, unless it is marked "read in code".
`_serve_kb` translates only `KbError`; any other exception becomes HTTP 500, and `_serve_read` maps only `DepthExceeded`.

**Ownership.** Findings in files that B5 may change are FIXED on `run6/b5-perf`, each with a test.
Findings in B1's files (`service.py`, `workspace.py`, `activity.py`, `data.py`) or in lead-only files (`kb_routes.py`, `index.py`)
are recorded with the exact fix, for the lead to apply after the merges. **Status** is FIXED, or FOR B1, or FOR LEAD.
