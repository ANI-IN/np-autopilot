## The rules (same in both)

| What | NP Autopilot (public/index.html) | KB (web/lib/kb/sync.py `np_categories`) |
|---|---|---|
| Legacy module | `adaptNode`: a module with no `domain_slug` | `is_legacy` = no `domain_slug` |
| Current domain | `model()`: offers at least one non-legacy module (`M.current`); the rest are `M.other` | same |
| Current instructor | `currentInstructors()`: an end of an edge with `tier: mastersheet` | same |
| Programmes | all shown as "older sheets" | all `is_legacy` |
| A legacy module's domain | a programme that `covers` the domain and `contains` the module (`M.legacy`, `domOf`); none = `M.unlinked` | same (used by the legacy step) |
| Roles P / B1 / B2 / B3 | `taught_by` with `tier: mastersheet`, `instructor_role` primary / backup_1..3 | relationship `teaches` (instructor -> module), `props.role`; the older sheets' `role` is kept apart as `props.older_role` |
| Sessions, decks, weeks of a module | `BY_MODULE`: `delivers_session`, `presented_with`, `scheduled_in` | module *contains* session / week; deck = link on the module with note "Slides" |
| Topics | one node per row (2,770) | one record per row: no merging by name (generic names are scoped to their only module; 5 remaining same-name pairs are kept apart with "(2)") |
